# S 战场动态预览：静态快照修订计划

**目标：** 以 Scene1 战场布局为基线，显示目标 Section 截至当前选中指令（含）的单帧结果。

**交互约束：** 随 TreeView 选中指令、条件和变量变化立即重算。不得提供播放、暂停、单步、速度、定时器、时间线、进度游标或中间帧。R 预览的现有播放功能不变。

**涉及技术：** C++17、MFC、cczPreviewCore 条件执行模型、GDI+ 地图绘制。

## 约束

- 每次目标 Section 的快照都从 Scene1 重建。
- Scene1 被选中时，直接显示已解析的 Scene1 布局，不重复应用其初始化指令。
- 目标路径包含所选指令本身，不包含其后的指令。
- 条件树和 Choice/Case 仅沿已选路径构建。
- 首版只投影 `0x32`、`0x55`、`0x58`；`0x6D` 忽略，其他未支持地图变化截断已知前缀。
- 移动/复活只更新 Scene1 中已有的单位记录；不按静态隐藏状态或格子占用设置资格门禁。
- 障碍物解析当前 Mod 的 `U_select.e5` 资源 19，采用帧 0、4、6。
- 保留已有未提交更改与构建产物，不做仓库清理或提交。

## 核心验证场景

1. 选中移动、复活或障碍指令时，结果包含该指令；选中其前一指令时，不包含后续操作。
2. 条件树下的目标前缀只包含可达分支，后置分支不会泄漏。
3. 两个 Section 顺序切换时各自独立从 Scene1 开始。
4. 同一单位经过移动再复活，最终地图只有一个实例且隐藏状态已清除。
5. 静态 UI 检查确认没有 S 播放器/进度/定时器符号；R 播放逻辑保持原状。
