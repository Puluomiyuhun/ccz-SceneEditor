# 全局模板库与代码检索实施计划

> 使用 executing-plans 逐项执行；用户要求自行实现，不使用子代理。

**Goal:** 保存、管理和复用完整指令树，并为选择代码接入十六进制直输和名称检索。

**Architecture:** 模板值模型独立于原生树；存储负责版本、锁和原子替换；停靠页负责管理；View 负责原子写入、跳转重映射与成组撤回。复用既有停靠系统和搜索控件。

**Tech Stack:** Win32 / MFC / C++17。

**Spec:** 本对话批准的模板库设计。

## 全局约束

- 序号、层级、名称、备注四列；保存入口位于原生树右键菜单。
- 全局数据保存在用户 AppData，关闭编辑器及切换剧本不会丢失。
- 保留完整参数、文本、子树；内部跳转重映射，外部跳转拒绝保存。
- 插入至选中位置之后，执行层级和 00/01 门禁，整组预检与撤回。
- 未选择位置时弹窗：请先选择需要插入新指令的位置。
- 代码直输采用十六进制；不改变人物与物品的十进制规则。
- 保留工作区已有修改；交付主程序及三个配套 ini。

## 任务

- [x] 模板值模型、结构校验、版本化存储编解码和损坏检查；覆盖参数、长文本、跳转及限制测试。
- [x] AppData 存储：加锁后重读、即时保存、原子替换、备份和明确错误。
- [x] 原生树抓取：同级有序选择、父子去重、保留子事件标记；不改复制缓存。
- [x] 原生树插入：层级预检、全部构建、跳转重映射、失败回滚、成组连续撤回和预览刷新。
- [x] 独立停靠面板：表格、搜索、树预览、插入、修改元信息、删除及撤回；接入整体显隐菜单。
- [x] 选择代码检索：复用搜索控件，稳定代码值和确认校验；测试十六进制及原有十进制兼容。
- [x] 编译、核心测试、原生 UI/持久化验证；打包四文件、核对哈希并出具报告。
