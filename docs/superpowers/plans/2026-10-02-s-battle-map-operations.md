# S 战场地图操作初版实施计划

## 范围

- 在 S 预览快速模式中新增 `0x32` 移动至、`0x55` 复活至和独立的 `0x58` 障碍摆放。
- 地图基线仍取已加载的 Scene1；新增指令锚定在用户当前选中的树指令之后。
- 移动与复活各自点击一次目标格并单条事务写入；障碍物只支持火、船、火船，先暂存再一次事务写入。
- 移动/复活不按 Scene1 的存活、在场或格子占用状态禁用；预览只显示指令目标格，不推演运行时避障。
- 所有原生写回复用现有事务、撤回、文档版本检查与 Scene1 基线重建。

## 步骤与验收

1. [x] 添加纯逻辑测试，覆盖三种指令字段、Data 号/地图坐标/障碍类型边界、障碍草稿顺序，以及任意 Scene 中选中指令的锚点校验。
2. [x] 增加受限指令构造器与 selected-sibling 原生批次构造器；明确 0x32/0x55/0x58 只允许 Insert，扩展插入撤回白名单。
3. [x] 扩展 S 预览工具 UI：移动从地图点选角色，复活从现有检索/直输武将列表选人，障碍面板用三类缩略图并在地图上暂存摆放。
4. [x] 使用统一目标格投影；失败时保留障碍草稿，成功后才清除；禁止工具点击进入多选或角色参数编辑。
