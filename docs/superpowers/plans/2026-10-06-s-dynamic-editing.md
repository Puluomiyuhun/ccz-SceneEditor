# S 动态预览分层编辑实施计划

**目标：** 动态关闭保留初始布置编辑；动态开启使用当前推演棋盘进行移动至、复活至和障碍物新增操作。

**实现：** 在 BattlePreviewPage 建立当前棋盘读取入口，动态选择保存为独立的文档会话状态。沿用原有地图操作构造、写入门禁、事务和最后写入指令定位。障碍物图片共用当前 Mod 的 U_select.e5 资源19帧0/4/6，失败保留手绘图标。

- [x] 修改 BattleMapOperations 障碍草稿队列，禁止同坐标新增，更新行为测试。
- [x] 修改 BattlePreviewPage / BattlePreviewSession：动态选择、点击及拖选读取推演棋盘；右键只开放移动/复活；朝向暂存和取消沿用原有流程。
- [x] 解除上述操作与障碍写入的动态门禁，保留初始布局编辑门禁及来源版本检查。
- [x] 草稿绘制独立于侧栏与工具模式；删除叠放计数；当前推演障碍物占据格拒绝新增。
- [x] 侧栏、草稿与推演共用图片，加载失败手绘兜底，缓存失败结果避免重复解析。
- [x] 构建 Release 和核心测试，检查写回、推演与模式维持回归；交付桌面四文件包并记录验证边界。

本轮不实现已有移动/复活指令的参数调整或障碍物默认参数。
