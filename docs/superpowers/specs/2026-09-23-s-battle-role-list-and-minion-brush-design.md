# S 战场角色列表与“小兵笔刷”设计

## 目的

在独立的 S 战场预览页加入原版战场布置器的角色选择与“小兵笔刷”工作流，使单位可通过单人选择或连续 Data 号笔刷临时落在地图上。角色列表和笔刷列表是 S 专属界面；它们不依赖 R 场景角色表。

本规格是 `2026-09-23-independent-r-s-preview-pages.md` 的增量变更：只替换其中“明确不迁移角色列表、场上单位只读”的限制；前缀路由、R/S 状态隔离、S 资源路径、全单位同屏、滚动缩放以及禁止剧本写回等其余边界继续有效。

## 交互设计

- S 页在地图旁提供一个独立侧栏，含“角色列表”和“小兵笔刷”两种列表视图。侧栏有自己的隐藏/恢复控件；隐藏后地图占满 S 页可用空间，地图上保留一个紧凑的恢复入口。隐藏和恢复不重置地图缩放/滚动，也不清除列表页、筛选或当前选择。
- 角色列表按 Data 号升序显示 S 角色名称，支持名称检索与分页。选择一个角色后，地图悬浮预览显示其 S 战场形象；地图上的单位不绘制名称标签。
- “小兵笔刷”依据角色名称派生连续 Data 号组：名称规范化时忽略 ASCII 数字；只有相邻 Data 号的规范化名称相同且连续数量至少为 3，才形成一条笔刷。笔刷标签由规范化名称生成，列表按组起始 Data 号升序显示。
- 选择笔刷后，悬浮预览使用组内下一个可用 Data 号。每次在合法地图格成功落笔只放置一个单位，随后自动推进到下一个可用号；非法格或失败操作不消耗号。组内耗尽时清除悬浮单位并显示明确状态，不回绕到组首。
- 第一阶段只支持逐次点击落笔，不实现按住拖动连续盖章、“开启复制人”或属性刷子。已有单位仍可通过现有 S 地图选择交互选中，但本阶段不提供属性修改入口。

## 数据来源与处理

- 新角色目录直接从当前 S 剧本对应 Mod 根目录的 `Data.e5` 读取；名称和兵种字段的偏移/编码以普罗工具 `BasicData2.ReadData` 的静态解析结果及本地样本交叉验证为准。解析失败时停止构建列表并给出 S 专属诊断，不回退到 R 角色表或 `m_pPer2`。
- 角色形象继续使用 S 页的 `BattleAssetCache`：Data 号、兵种、`Ekd5.exe` 外观表与 `Unit_mov.e5` 的既有映射生成战场帧。此功能不得调用 R 的角色目录、立绘缓存或预览 session。
- 列表搜索按名称子串匹配；空名称仍以 `Data <编号>` 占位显示，不静默丢失有效 Data 记录。笔刷规范化仅用于分组标签与匹配，不改写原始名称。
- 笔刷可用号按组内升序选择，并跳过当前 S Battle 状态中已占用的 Data 号及本次会话已临时放置的 Data 号。该阶段不提供复制已用 Data 号的开关。

## 放置与状态边界

- 选择角色或笔刷只更新 S 页自己的编辑状态和地图悬浮预览，不影响 R 页状态。
- 落笔仅允许绑定到 `BattleEditorOps` 已支持且字段语义闭合的放置指令来源，并通过现有边界、地形和占格校验。没有有效放置来源、地图投影/地形不完整或目标格非法时，拒绝放置并显示原因。
- 成功落笔仅更新 S 页的临时 `BattleEditorState`，用于当前窗口即时显示；不修改 TreeView、原始 EEX 字节、剧本文档或磁盘文件。刷新/重新加载剧本会丢弃这批临时落笔结果。
- 角色列表选择使用单一 Data 号；笔刷选择保存组范围与当前游标。切换角色/笔刷时不得误把既有地图单位改成所选角色。
- 属性刷子（外观/兵种、隐藏、朝向、等级、类型、目标）、角色级别属性编辑、EEX 写回与写回撤回均不属于本阶段。原有 R 预览的撤回栈也不得被 S 页调用。

## 实现边界

- 在 `cczEditor2/PreviewIntegration` 增加可独立测试的 S 角色目录/笔刷分组模型；UI 仅展示该模型并将选择、翻页、筛选、落笔请求转交给 S 页状态与 `BattleEditorOps`。
- `CSBattlePreviewPage` 负责侧栏与地图画布布局、侧栏显隐、悬浮单位绘制和刷新。地图画布尺寸变化时更新既有视口/滚动条范围；显隐侧栏不得重置视口的缩放和滚动位置。
- 新的数据模型和 UI 只能由 S 页创建、持有和销毁。R 前缀文档、未知前缀文档不得创建或显示 S 列表；S 切换/清理不得污染 R 预览诊断。
- 不实现属性刷子、不增加剧本保存/写回路径、不增加拖动盖章、不改普罗工具或游戏引擎。

## 验收标准

1. S 页可在“角色列表”和“小兵笔刷”间切换；角色列表搜索/分页结果稳定，按 Data 号顺序显示；角色名称来自 Data.e5 而非 R 角色表。
2. 分组测试覆盖：不足 3 项不成组、非连续 Data 号断组、名称中的 ASCII 数字忽略、规范化名称变化断组、连续 3 项成组。
3. 选择角色/笔刷时悬浮帧使用正确的 S 形象映射；在合法格落笔后全单位同屏更新，笔刷推进至下一个未占用号，失败格不推进，耗尽时不回绕。
4. 侧栏隐藏后地图使用完整可用区域，恢复入口可用；隐藏/恢复往返保留列表状态及地图缩放/滚动位置。
5. 非法放置上下文、越界/阻挡/占用格和不完整地形均 fail closed；任何落笔都不修改 EEX 文件或 TreeView；重新载入会还原文件解析出的状态。
6. 静态依赖/合同测试确认 S 新代码不引用 R 角色表、R 资源缓存、R PreviewSession 或 R 撤回状态；属性刷子入口不存在。
7. 相关 PreviewCore/编辑器测试和 Win32 构建通过。真实窗口验收仍由用户确认侧栏显隐、可视尺寸、形象及实际操作手感；构建通过不代替实机验收。

## 有意保留的兼容性边界

普罗工具报告确认了角色目录和“小兵笔刷”的主要构造/落笔算法，但完整显示排序、复制人开关语义及引擎 EEX 保存后的 0x46/0x47 记录回读尚未闭合。此规格只复现已确认的角色来源、连续分组和逐次自动推进；任何未闭合的持久化或复制行为保持关闭，不依据名称猜测。
