# S 战场角色列表与“小兵笔刷”设计

## 目的与边界

在独立 S 战场页增加原版布置器的角色目录与连续小兵笔刷，并把单位以临时编辑状态显示在地图上。角色目录来自当前 S Mod 的 `Data.e5`；此功能不得依赖 R 角色表、`m_pPer2`、R 资源缓存或 R 预览 session。

此阶段支持：角色列表/检索、连续小兵组列表、单人放置、按住左键连续盖章、右键删除、组内可用 Data 号复用、值级撤回、侧栏显隐。暂不接属性刷子、EEX 文档写回或磁盘保存。写回必须继续通过现有五项证据门，不能用合成测试证据开放产品入口。

## 已确认交互

- 侧栏含“角色列表”“小兵笔刷”两个页签，支持隐藏/恢复。显隐不得清空筛选、页码、选项或视口缩放/滚动。
- 角色列表按 Data 号升序呈现 S 角色名，支持名称/编号筛选及分页。单人选择后进入放置模式；已在当前战场中的 Data 号不可重复放置。
- 笔刷从相邻 Data 号的角色记录按名称规范化分组：仅移除 ASCII `0`–`9`；相邻、规范化名称相同且组长至少 3 才生成笔刷。每次有效盖章用该组当前最小可用 Data 号。
- 按住左键时，在鼠标进入新的合法逻辑格时盖一个单位；同一格不重复尝试。越界、占格、地形禁放、上下文不完整或来源槽不可用均不消耗 Data 号。
- 右键命中唯一单位时快速删除。0x46/0x47 固定记录清为空槽 sentinel 并保留原 record_index；0x4B 可变记录按现有适配规则移除并调整同源后续 record_index。
- 删除只释放该单位 Data 号，不给其他幸存者重新编号。之后同组选择优先复用最小可用号。不得在删除或写回时把 358/360 重排成别的编号，也不得压缩幸存单位 ID。
- 单位放置方向、隐藏、等级、兵种/类型、援军、AI/方针、目标等属性本阶段不提供控制，使用实现中明确的默认值；仅在字段语义完整且来源有效时允许临时放置。
- 所有新增/删除均只改 S 页内存状态；Undo 恢复战场快照及选择状态。刷新/换文档丢弃临时改动。剧本文档/磁盘不变。

## S 数据目录

- 使用当前 S 剧本 Mod 根目录 `Data.e5`。编辑器源码确认：大表头 396 字节，角色记录 32 字节，名称字段位于记录起始、宽 12 字节并按 CP936 解码，兵种/arms 字段位于记录偏移 26；选择 512 或 1024 条记录的边界必须按普罗 `BasicData2.ReadData` 与实际文件长度规则实现，并用样本校验。
- 外观仍由独立 S `BattleAssetCache` 通过 Data ID、arms、EXE 外观表与 `Unit_mov.e5` 解析。不要把名称文本叠加到地图单位上。
- 空名有效槽用 `Data <编号>` 展示，不静默丢失；非法记录/CP936 失败要报告目录级 S 诊断，不回退到 R 数据。
- 笔刷可用号根据当前 Battle 作用域的已解码单位即时计算，不另存一个可能与地图状态分叉的“已用”缓存。删除后可自然复用，撤回后也按撤回后的单位状态重新计算。

## 槽位和撤回

- Data ID 是战场角色身份，record_index 是指令中的固定行号；两者不可混用。
- 对 0x46/0x47 固定记录，放置优先写入同来源最小 sentinel 空行，否则仅在容量允许时按现有字段契约扩充候选行。删除永远清空原行而不 erase/shift。
- 0x47 每条承载多单位并可有连续多条指令；本轮不合并来源节点，也不改变来源顺序。没有可靠来源节点/容量/字段证据时 fail closed。
- 0x4B 保留其独立来源/记录语义；不把它当作可任意合并的批量槽。
- 单次落笔/删除各为一个 S undo 事务。尚未打开原生文档写回，因此所谓写回撤回也尚不触发 TreeView/EEX 变化。

## 原生写回门

现有 `BattleWritebackEvidence` 的字段表、样本清单、组内顺序、编辑器原生重载、kind 300 接受五个证据必须全部完成后，才可实现文档层一次性写回与撤回。静态 adapter、临时缓冲区或单元测试合成证据不构成门槛通过。本轮如证据未闭合，只交付可操作的内存布阵；UI 需明确标注临时态，不能显示成功写回。

## 验收

1. `Data.e5` 解析的名称、兵种以及记录数与 S 样本/Pro 静态规则一致；R 文件与 R 预览行为不受影响。
2. 分组测试覆盖：组长小于 3、Data 号不连续、规范名不同、ASCII 数字忽略、连续三项成组。
3. 笔刷从最小可用号开始；每次成功放置后推进；非法格不推进；删单位后最小空闲号可复用；幸存单位 Data 号稳定；耗尽时明确提示且不回绕。
4. 左键按住进入新格连续落笔，单格不重复；右键只删命中的唯一单位；固定记录 sentinel 和 record_index 稳定。
5. 本阶段只实现并验证 Undo；撤回落笔/删除后地图与 ID 可用性一致。不得借用 R undo 栈。
6. 侧栏隐藏/恢复保留 S 页面状态，恢复入口有效。
7. 临时编辑不改变 TreeView、原始文档缓冲区、文档 dirty 标志或磁盘文件。没有完整写回证据时不存在可执行写回入口。
8. 定向测试与 Win32 Debug/Release 构建通过；真实窗口的可用性仍由用户验收。
