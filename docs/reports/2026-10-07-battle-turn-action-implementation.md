# S预览朝向与动作增强工作报告

## 已实现
- 动态推演加入4F战场转向设置、50战场动作设定，沿用Scene1基线、前置Section、条件树及当前指令位置。
- 角色右键新增调整朝向、朝向武将、战场朝向参数、设置战场动作，支持单体及多选。
- 恰好双选时提供武将相对，成对写入A朝向B、B朝向A，共用一次撤回。
- 调整朝向滚轮只改变临时画面，确认后写入；取消恢复。写入使用现有门禁、末条选择及自动启用动态预览逻辑。
- 常规DATA号和战场编号均可解析；V0、变量及特殊选择器跳过并诊断，不阻断后续指令。
- 动作素材读取当前Mod的Unit_mov、Unit_atk、Unit_spc；攻击64像素帧保持居中。

## 核对结果
- Release Win32编译成功。
- 474项核心回归测试通过，包括指令回退、参照角色移动后转向、互相朝向、编号模式、R/S解析隔离、成组写回。
- 56组生产素材解析及实际主引擎E5图片解码通过。
- 主引擎18份S剧本扫描：4F共778条，50共803条；发现111组相邻相互转向实例。

## 实现范围
- 战场动作展示代表性的静态姿态，不播放动画，不产生伤害、恢复或异常状态。
- 4F有参照武将时按其推演坐标计算朝向，参照优先；无参照且默认方向时保持当前方向并提示。
- 本轮验证包括编译、推演/写回回归及实际素材解码，尚未完成新版所有右键操作的人工界面验收。
