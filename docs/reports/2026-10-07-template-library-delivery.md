## 使用方法
1. 左侧选择需要保存的同级指令，右键“存入模板库…”，填写名称和可选备注。支持完整子事件、Section、Scene；父子重复选择会去重。
2. 个性化 → 属性栏和菜单栏 → 模板库控制显隐。模板库为独立停靠页，可收纳、浮动；初次默认与场景预览共用标签停靠区。
3. 表格依次为序号、层级、名称、备注；支持检索、内容树预览、插入、修改名称备注、删除和插入撤回。
4. 选中目标位置后插入模板，指令写到选中位置之后，并选中最后插入的根指令。未选择位置会弹窗“请先选择需要插入新指令的位置”。
5. “选择代码”支持名称检索和十六进制直接输入，例如 14、4D、58、0x58。人物、物品的原有十进制输入规则保持不变。无效输入保留待改文本，不接受此前代码。
