# S预览悬浮刷新修复
## 根因与修改
障碍物多选启用时，OnMouseMove在更新hoverCell后直接返回，没有Invalidate；点击操作才触发绘制，因此格子高亮、坐标与信息卡需要点击后才更新。普通分支同一格内鼠标移动也不刷新卡片位置。
将hoverPoint、hoverCell、必要Invalidate及光标更新放在共用路径，在障碍物早返回之前执行。重复相同位置不追加重绘，原选择与笔刷逻辑保留。
## 验证
执行提取的生产OnMouseMove函数：修复前回归失败，修复后验证普通/障碍物多选悬浮、同格跟随、离开画布、无点击不编辑、障碍物选择和笔刷通过。
476核心测试通过；Release Win32编译成功。未对运行中用户编辑器强制替换或关闭；新exe需要另行启动验收。
