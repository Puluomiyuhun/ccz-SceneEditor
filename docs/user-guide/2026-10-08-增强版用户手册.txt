cczSceneEditor2 增强版用户手册
编写日期：2026年10月8日

============================================================
一、增强版与原版的区别
============================================================
本手册说明在 GitHub 原版基础上新增、扩展的功能，以及相应使用方法。
原版来源：https://github.com/Puluomiyuhun/ccz-SceneEditor
对照基线：本地保存的 origin/main，提交 e75b2e1。

原版已经提供剧本树编辑、基础场景预览、角色列表，以及单体调整位置、设置朝向、设置动作、移动、消失等功能。这些不算增强版从零新增的功能。

增强版主要新增或扩展：
1. 场景预览按 R/S 剧本自动切换，各自使用对应的地图、模型和指令逻辑。
2. R 预览的条件模拟、动态回放、批量操作、主角色对齐、精准等距、连续撤回及角色删除。
3. S 战场预览：三类出场指令解析、角色布置、小兵笔刷、参数修改、地形检查、批量编辑、写回及连续撤回。
4. S 动态预览：以 Scene1 为基线推演到当前指令，支持条件树、变量模拟及前置 Section 关联。
5. S 移动、复活、障碍物和多种战场指令的地图操作入口。
6. 我军槽位与 DATA 号的预览绑定。
7. 全局模板库，以及代码、人物等选择框的直输/检索增强。
8. 模型悬浮详情、状态与暂存标签、独立地图工具、侧边栏收纳及界面刷新改进。

本手册对应当前交付版本；最新功能仍在手动验收中。预览是编辑辅助，不等于完整运行游戏引擎。

============================================================
二、准备文件与打开窗口
============================================================
1. 从交付文件夹运行 s.exe，保留同目录的 CczCustom.ini、CczString.ini、CczSceneEditor2.ini。
2. 打开需要编辑的 R_*.eex 或 S_*.eex。建议直接打开所在 Mod 的剧本，不要只拷贝一份 eex 到没有资源的目录。
3. 地图、人物、头像和动画读取对应 Mod 的资源，例如 map、Data.e5、Hexzmap.e5、单位形象文件、U_select.e5、Mcall.e5、Meff.e5 等。
4. “个性化 → 属性栏和菜单栏 → 场景预览”控制预览窗口显隐；同一菜单下的“模板库”控制模板窗口显隐。
5. 这些窗口可停靠、浮动或通过标题栏图钉自动收纳；收纳后可从边缘标签重新呼出。
6. 打开 R/S 剧本后，场景预览自动显示相应页面，不需要手动选择另一种解析模式。

提示：模型、头像或地图缺失时先看预览下方诊断栏。障碍物图片加载失败会使用手绘图标；其他资源缺失不代表可以完整模拟其效果。

============================================================
三、先分清三种修改状态
============================================================
【模拟】条件树、模拟变量、前置关系、我军预览绑定主要用于决定预览结果，不会把模拟状态当成游戏状态保存进剧本。
【暂存】S 普通布置及障碍物笔刷产生的改动可能先放在预览缓存。“暂存”标签位于对象下部。点击“写回”才提交到左侧剧本树。
【已写入】移动至、复活至及战场操作等立即指令，在确认后直接写入左侧剧本树。已有源指令的调整也可能直接修改源指令。

无论通过哪种方式修改树，仍需使用编辑器正常“保存”命令保存 eex。写回与保存文件是两步。

需要插入新指令的立即功能，使用前须在左侧选好插入位置。未选择时弹窗：
“请先选择需要插入新指令的位置”
可用位置还需满足原有层级和子事件结构规则；选了节点不意味着任何位置都允许插入。

============================================================
四、R 预览增强
============================================================
4.1 静态预览与条件模拟
在左侧选择指令，预览显示当前路径推演到该位置的场景。
“条件树”：查看当前条件与分支，可设置判定为真/假、恢复默认；针对支持的整型条件可设置模拟值，分支选择可恢复自动。
“变量控制”：检索变量，修改支持的模拟布尔/整型值，观察不同路径的预览。
“激活子事件”：当前指令所在子事件因条件而不可达、且支持激活时出现；点击后在预览中激活相应路径。它不是修改剧本条件的按钮，也不是永远显示的按钮。

4.2 动态回放
地图下方提供回放工具条，鼠标悬浮按钮可查看说明：
- 从开头播放到当前选定节点。
- 从当前选定节点播放到结尾。
- 回到当前播放模式起点。
- 播放/暂停。
- 停止并恢复静态预览。
- 后退一步、推进一步。
- 切换播放速度，查看进度与步骤计数。
回放过程中不进行地图编辑；先停止回放，再调整角色。

4.3 多选与批量编辑
在空闲画布中依次点击角色，切换各自的选中状态；选中多个角色后右键成员，打开批量菜单。
新增批量功能包括：
- 统一动作、统一朝向、批量消失。
- 批量移动 → 组移动：保留成员相对位置。
- 批量移动 → 点移动：将成员移动到同一逻辑坐标。
- 对齐 → 快速对齐。
- 对齐 → 对齐主角色 → 同 X 坐标/同 Y 坐标。
- 等距 → 一键等距。
- 等距 → 精准等距 → 按 X 坐标/按 Y 坐标。
- 设为主角色、取消选择该角色。

先在多选菜单中将某成员设为主角色，再使用依赖主角色的对齐或移动。精准等距用于沿指定轴均匀分布；成员过少或本来已经符合布局时可能没有变化。

位置调整/移动会显示目标预览，按地图操作提示点击确认或取消。角色操作中普通滚轮调整方向；Shift+滚轮涉及动作。尤其在调整位置时，Shift+滚轮可能直接新增动作指令，不应当把它当成只改变临时朝向的操作。

4.4 删除与连续撤回
“消失”是插入消失指令；“删除角色”删除其对应的出场节点，二者用途不同。
“撤回”支持连续撤回预览编辑产生的多次操作，不再点击一次就销毁按钮。无记录时按钮禁用。
连续撤回受记录有效性限制；切换文档、重新读取或其他修改导致来源失效后，不能把旧记录视为跨会话的通用历史。

4.5 外场景地图头像
对支持的外场景地图头像，可从对应对象右键调整位置、移动或消失；地图头像坐标与普通角色坐标按各自模式解析。头像没有角色动作和朝向，不使用角色滚轮动作规则。
状态栏按当前场景匹配角色或地图头像统计。

============================================================
五、S 普通战场预览与布置
============================================================
5.1 模式与视图
“快速模式”默认启用，普通布置读取 Scene1 的战场基线；关闭后使用普通读取方式。模式和作用域是否可编辑以按钮状态及诊断为准。
上方显示地图、尺寸、缩放及单位统计；悬浮格子显示坐标、地形和单位详情。
“预览切换”可显示战场编号、等级、兵种级别、行动方针、援军，或关闭参数标签。
Ctrl+滚轮缩放地图；中键拖动平移，也可使用滚动条。放置、调整、移动、复活时，普通滚轮用于方向选择。

5.2 新增角色
1. 关闭动态预览，打开“角色/笔刷”侧边栏。
2. 在出场类型中选择我军出场（4B）、友军出场（46）或敌军出场（47）。
3. “默认参数”配置后续新增单位使用的参数；已有单位通过右键“修改单位参数”修改。
4. 选择角色，移动鼠标查看半透明落点，滚轮选择方向，点击合法格放置。
5. 暂存单位显示下部“暂存”标签。可继续修改或清空，最后点击“写回”。

三类出场的字段不同；我军槽位不能按敌/友军专有属性理解。
已有出场范围可被安全识别时，新出场记录按对应出场类别归入该范围；无法唯一确定时按提示选择合法位置，不任意猜测归档位置。

“复制人”：控制重复使用同一角色的放置行为。
“无地形限制”：用于有意绕过放置地形检查；常规布置不建议长期勾选。
默认按兵种及地图地形检查落点；我军已绑定 DATA 时按绑定人物解析，未绑定时按 0 号兵种检查。

5.3 小兵笔刷
切到“小兵笔刷”，选择一个连续小兵系列。按住左键沿地图刷入，经过的合法格逐个显示单位；非法格不消耗下一名小兵。
普通滚轮改变笔刷方向，右键取消笔刷操作。
可清空新暂存角色；清空不删除已写入的原生角色。清空及笔刷操作可通过预览撤回恢复。

5.4 角色多选及普通编辑
依次点击角色切换选择；按住左键拖动可沿路径选取。右键选中成员使用批量调整位置、批量修改参数、批量删除，以及按阵营筛选。
位置调整显示半透明预览，滚轮调整方向，按提示确认或取消。
普通布置改动先暂存，写回后再保存剧本。

============================================================
六、S 动态预览
============================================================
6.1 开启与推演范围
点击“激活动态预览”开启；按钮变为“关闭动态预览”。再次点击关闭。
这里的“动态”表示根据指令位置推演结果，不是像 R 回放一样播放整段剧情。

基本顺序：Scene1 初始布局 → 当前 Section 的有效指令流 → 左侧当前所选指令。
Scene1 自身包含的移动、复活、显隐等指令也纳入相应推演。
前置关联开启时，改为 Scene1 基线 → 前置链 → 当前 Section → 当前所选指令。
切换指令、Section 后自动更新结果；用户未主动关闭时保持动态预览开启。
移动/复活后只显示结果位置，不重复显示原来的形象；上部标签简写为“移动”“复活”。
关闭动态预览后恢复原有布置工具；条件树及变量控制仍按适用状态提供。

6.2 可推演的主要内容
- 武将移动（32）、战场复活（55）。
- 隐藏武将出现（4C）、武将消失（31）、武将撤退（53）。
- 战场障碍设置（58）的显示、消失与位置结果。
- 武将状态变更（4D）、方针变更（4E）。
- 战场转向（4F）、战场动作（50）。
- 高亮区域（5B）、高亮人物（5C）、法术（6B）的当前指令预览。
这里的代码均按十六进制记载。

DATA 号与战场编号按指令的实际参数模式匹配，不要求用户手工转换两种编号。
V0、变量型或其他特殊对象选择器不作为常规对象支持；相对移动不在本版支持范围。
无法确定我军 DATA 或变量状态时，看诊断栏；部分指令会跳过无法匹配的目标，未知条件也可能使路径不能继续确定。

6.3 恒常结果与一过效果
移动、复活、显隐等影响后续推演结果。
战场动作、高亮区域、高亮人物、法术属于一过效果：只在选中对应指令时显示；切走后清除该效果，动作恢复通常姿态。
法术只播放视觉动画，不模拟伤害、恢复或异常。
动画可直接读取当前 Mod 的 Mcall/Meff 资源和播放序列；预览时序及部分高级混合效果不等同游戏效果。

6.4 前置 Section 关联
鼠标移到动态预览按钮上，打开菜单：
“常规预览”下有“使用前置关联”“不使用前置关联”。
另有“添加前置 Section…”和“调整前置 Section…”。

例：想让 B 中消除 A 新增的障碍物：
1. 左侧选中 B 内的一条实际指令。
2. 选择“添加前置 Section…”，从列表选 A，点击“设为前置”。
3. 启用“使用前置关联”，A 的结果先参与 B 推演。
4. 要在 C 接着使用结果，选 C 内指令，再把 B 设为 C 的前置，形成 A→B→C。

Section 名称取其内部信息；未填写时显示未命名及 Scene/Section 编号。
每个当前 Section 只设一个直接前置；可组成链，不能自连、重复或循环。
“调整前置 Section…”是当前剧本所有关联的总览，可移除关系、定位当前 Section，不只是当前一项。
“不使用前置关联”临时忽略关系，不删除已设置的关系；关联提示只在实际使用前置链时显示。
关联在当前文档会话中保留，切换 Section 不丢失；不保存进 eex，不保证重启编辑器后保留。Section 删除、移动或树重建后可能需要重新设置。

============================================================
七、移动至、复活至与动态位置调整
============================================================
7.1 写入移动/复活
1. 在左侧选好新指令插入位置。
2. 右键已有战场单位，选择“移动至”或“复活至”；多选后可批量操作。
3. 移动鼠标查看半透明目标；普通滚轮调整方向，点击确认。右键/Esc取消临时操作。
4. 成功后插入相应新指令，左侧选中最后写入的一条。
5. 原先未开启动态预览时自动开启；已经开启时维持其状态并刷新结果。

复活针对已在剧本中安排出场的单位，不是从全 DATA 列表新增一个出场人物。
“在场”表示战场正常存活；隐藏、被击杀或剧情离场等“不在场”，仍可属于已安排出场的单位。不要与“剧本从未安排出场”混淆。

7.2 动态预览中的“调整位置”
右键单位选择调整位置；多选可批量调整。
没有经历有效移动/复活的单位：修改初始出场坐标。
已经移动/复活的单位：修改当前指令之前最新有效的移动/复活源指令坐标。
因此，“调整位置”修改现有来源，“移动至/复活至”新增指令。
滚轮修改本次预览方向，确认后提交；取消不保留临时变化。

============================================================
八、地图工具与障碍物
============================================================
8.1 连续添加
1. 打开“地图工具”，选择火（0）、船（1）或火船（2）略缩图。
2. “默认参数”设置之后新增障碍物使用的显示状态、地形、视点、音效；类型由略缩图决定，坐标由点击格决定。
3. 点击或按住左键连续添加。障碍物先暂存，下部显示“暂存”。
4. 同格障碍物不允许叠放；更改侧边栏或隐藏侧边栏不清除暂存预览。
5. 点击“写回”，为暂存项写入 58 指令。成功后选中最后新增指令并启用/维持动态预览。

略缩图优先取当前 Mod 的 U_select.e5；加载失败使用手绘图标。
“清空”移除暂存障碍物，不代表把已经写入的障碍物全部消失。

8.2 单体编辑
右键障碍物可调整位置、修改参数。
已写入对象修改对应 58 源指令；暂存对象修改缓存。
“消失”对已写入对象新增显示参数为“消失”的 58 指令；暂存对象直接移除草稿。
与角色同格时先选择“操作角色”或“操作障碍物”。

8.3 独立多选
点击“多选障碍物”，独立选择障碍物，不混入角色选择。
- 单击切换选中，紫色框标明成员。
- 按住左键拖选，超过拖动阈值后重新建立分组，包含起点、沿途和末端。
- 右键选中成员可调整整组位置、批量修改参数、消失。
- 右键未选障碍物按单体操作。
- 批量移动保持相对位置，以右键成员为锚点；目标显示半透明图像。
- 合法位置紫色框；越界或与非选中障碍物冲突为红色框，并在诊断栏提示。
- 左键确认；右键/Esc取消移动但保留选择。
- 关闭多选清空分组；切换 Section 清空分组；切换指令取消正在进行的移动。
- 批量参数只更改勾选字段。来源变化后可能要求重新打开参数窗口。
- 暂存和已写入障碍物可组成混合组，按各自写入状态处理；组操作整体撤回。

============================================================
九、其他 S 指令的地图操作
============================================================
9.1 角色右键：单体及批量
“隐藏武将出现”（4C）、“状态变更”（4D）、“方针变更”（4E）、“高亮人物”（5C）、“法术”（6B）、“武将消失”（31）、“武将撤退”（53）。
选中角色后右键进入功能，填写其余参数，再应用。
这些指令的 DATA/战场编号选择遵循实际指令格式。绑定我军需要选择参数模式时，弹窗“是”表示 DATA 号，“否”表示战场编号，“取消”中止。
隐藏武将出现支持单体及批量：左侧选好插入位置，右键角色选择“隐藏武将出现”或“批量隐藏武将出现”。提交时从当前预览检查隐藏状态，只为隐藏角色写入4C；未隐藏角色跳过，全组未隐藏则不写入。沿用DATA/战场编号模式，成功后选中最后指令、启用或维持动态预览，一组可整体撤回。
消失与撤退在本预览中都使单位隐藏；不模拟两者不同的游戏动画。
状态变更展示支持的状态信息；不凭空推断未知的初始 HP/MP 或完整战斗结算。

9.2 朝向、动作及两人相对
“设置朝向/统一朝向”：选择北、东、南、西，按弹出的延迟设置确认后写入 4F。
“朝向武将/批量朝向武将”：选择作为参照的另一单位，按其推演位置计算方向。
恰好选中两名角色时，“武将相对”写入 A 朝向 B 与 B 朝向 A 的一对指令，可整体撤回。
“设置战场动作/批量设置战场动作”写入 50。动作只在当前对应指令选中时预览，不长期保留姿态。
有延迟参数时，一组操作的前延迟放在首条、后延迟放在末条。

9.3 地图工具内的区域/地点操作
展开“区域操作”：
- 区域状态变更（4D）。
- 区域方针变更（4E）。
- 高亮区域（5B）。
- 法术（6B）。
- 区域武将消失（31）。
- 区域武将撤退（53）。
- 进入地点测试（25）。
- 进入区域测试（26）。
- 我军预览绑定总览。

操作顺序：先在左侧选择插入位置 → 点击功能 → 在地图取点/框选 → 设置剩余参数 → 应用。
地点测试和地图法术先点击格子；区域类按住左键框选，松开后进入参数窗口。
区域指令的阵营筛选整合在参数窗口，不必先选择地图人物。
25/26 的角色使用原编辑器完整列表：DATA 人物、任何部队、我军或友军、敌军、我军当前人物、w0～w249、v0～v4095 和无；不限制为当前在场单位。可按名称或 w/v 文本检索。特殊角色可写入，但不代表预览能确定所有特殊角色的游戏运行结果。
测试指令是条件测试，不是把人物移动到目标点。方针的目标坐标也不等于区域的边界坐标。
高亮和法术写入后选择该指令查看效果；选择其他指令后效果清除。

============================================================
十、我军预览绑定
============================================================
我军 4B 通常只给出我军槽位，预览未必知道实际 DATA 人物。
单体入口：右键该我军棋子 → “我军预览绑定”。
总览入口：地图工具 → 区域操作 → “我军预览绑定”。
选槽位、选择或直输/检索 DATA 人物，应用后重新推演；可取消绑定。

绑定后按该 DATA 绘制模型、头像和名称，并用于相应兵种地形检查；仍保留我军语义，不补上敌/友军专用属性。
未绑定的我军槽位使用占位显示。需要 DATA 的指令可能无法精确匹配，诊断会说明；能使用战场编号的操作可按编号模式使用。
绑定用于当前预览会话，不是把我军出场指令改成敌军式 DATA 出场，不写进 eex，也不是永久人物名单。

十一、全局模板库
============================================================
11.1 保存模板
1. 在左侧选择一组需要复用的同级指令，也可选择完整子事件、Section 或 Scene。
2. 右键 → “存入模板库…”。
3. 填写名称与可选备注，确认保存。
父子重复选择会去重。模板保留参数、长文本和子树；不只是保存显示文字。

11.2 浏览及插入
打开“模板库”，表格依次显示序号、层级、名称、备注；可检索并查看内容树。
选中左侧目标位置，再选模板并点击“插入模板”，或使用模板库右键入口。
按原有粘贴规则检查层级和子事件结构；成功后选中最后插入的根指令。
可修改名称/备注、删除模板、连续撤回模板插入。
“撤回插入”只撤回模板插入记录；其他内容修改使记录失效时不继续误删。

11.3 持久化与跨 Mod
数据默认位置：
%APPDATA%\cczSceneEditor2\TemplateLibrary\library.czt
关闭编辑器、切换剧本或换交付文件夹不会丢失该用户的模板库。
换电脑或 Windows 用户需迁移模板数据目录。
模板内部跳转会随插入重映射；指向模板外部的跳转不能作为完整独立模板保存。
DATA、战场编号、地图等参数按原值复用。跨 Mod 使用时请核对这些编号，不会自动改成另一 Mod 的对应人物。
损坏、存储冲突等看模板库状态提示，不要把插入失败当成已经成功写入。

十二、选择框直输与检索
============================================================
“选择代码”框支持名称检索和十六进制输入，例如 14、4D、58、0x58。
人物编号仍按十进制，例如 26 表示 DATA 26，不表示十六进制 0x26。
已接入的物品/人物选择框可按名称检索。过滤列表只改变显示，不改变最终编号。
输入无效值或空值后不能沿用之前的旧选择；请重新输入并确认有效条目。

============================================================
十三、常见问题
============================================================
问：为什么按钮灰色？
答：可能未读取有效战场、动态模式不允许该类原始布置、存在未提交改动、没有合法对象，或剧本来源已变化。先看诊断，不要只反复点击。

问：写回后关闭程序，改动怎么没保存？
答：写回提交到树；还必须保存 eex。暂存缓存也不能当成已经保存的文件。

问：动态预览“无变化”一定是没有解析吗？
答：不一定。当前有效路径可能没有支持的变化、条件未激活、指令在当前位置之后、对象无法匹配或结果本来相同。查看条件树与诊断；明确存在应生效指令时再报告具体剧本和选中节点。

问：为什么法术/动作切走就没有了？
答：属于一过式预览，是本版设计行为。

问：在其他 Section 消除前一 Section 的障碍物却看不到它？
答：设置前置 Section 关联并选择“使用前置关联”。默认不会把所有无关 Section 顺序执行一遍。

问：隐藏侧边栏后怎么撤回或写回？
答：S 顶部工具条保留撤回/写回，不依赖侧边栏展开。

问：预览会完整模拟真实战斗吗？
答：不会。它聚焦受支持的指令、对象和条件；特殊选择器、相对移动、完整战斗结算、高级动画混合等不在完整模拟范围。游戏实机仍是最终验证。
