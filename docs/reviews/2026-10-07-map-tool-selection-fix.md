# 地图工具取点与框选修复

2026-10-07。验收反馈：地图工具直接打开坐标参数框，没有先进行地图选择。

## 修改
- 25 地点测试、6B 法术：入口进入地图取点，点击有效格子后打开参数设置。
- 26 区域测试、4D 区域状态、4E 区域方针、5B 高亮区域、31 区域消失、53 区域撤退：入口进入框选，拖动展示蓝色范围，松开后打开参数设置。
- 坐标自动填入，反向框选自动归一化，端点包含；25/26 继续使用全 DATA 列表。
- 右键、Esc、丢失鼠标捕获取消地图选区，松开在地图外不弹参数框。
- 未完成的地图选区不跨剧本保存；保留原有角色操作及暂存障碍物。
