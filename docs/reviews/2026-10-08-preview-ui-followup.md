# 第二轮预览界面验收修复

依据用户《进一步调整回馈.txt》13条需求及后续根因核对。用户批准动手后完成本轮代码调整。未使用子代理，未提交或关机。

## 修改

- 清空障碍物布局与刷新统一常驻、空暂存禁用；多选文字由当前真实状态更新。
- 未绑定我军默认选DATA 0，已有绑定继续选原值。
- 工具栏布局完成后统一使父/子窗口失效，避免不重绘移动的撤回/写回保留旧画面。
- 障碍物逐格添加保留；将全控件刷新移出逐格路径，复用33ms地图刷新；松开及捕获中断补齐控件更新。保留补齐轨迹和整笔撤回。
- 参数窗口按可见字段采用一/两列并计算尺寸；是非型朝向、动作延迟、法术视点改勾选框。
- 朝向三种入口统一延迟设置；一组的前延迟落在首条、后延迟落在末条；取消不写入。移除冗余参数入口。
- 地图工具隐藏复用现有隐藏入口并修正页面状态判断；切回角色页清除冲突工具，保留暂存。
- 角色清空仅把editor_staged_new的有效暂存单位加入删除组，复用现有单笔撤回，不删除原生角色或重置既有参数编辑。
- 动态预览按钮保持现有直接点击开关，显示明确的激活/关闭文字，保留悬浮关联菜单。
- 区域操作展开/折叠列表保留所有原入口，包括完整DATA地点/区域测试及总体我军绑定。
- 状态变更采用紫红描边与悬浮信息色；精简常用操作的省略号。
