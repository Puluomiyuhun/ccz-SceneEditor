# S 动态预览指令流修复 — 2026-10-07

## 现场证据
直接读取运行中的新版编辑器进程 18120 的 TreeView 和预览对象内存。只读取原有对象；用于查询 TreeView 的临时远程缓冲区已释放，未保存、覆盖或修改用户剧本。
选中指令为 0x5A；上方确有四条 0x58 火障碍物以及四条 0x32 移动。
动态预览启用且就绪，选中指令映射正确，实际动态计划为空且 path_complete=false。
诊断是“S 指令目标未部署或编号不唯一，预览停在该指令之前”。
在这八条地图指令之前，原剧本已有三条 0x4D 对 Data 0 的状态变更。Scene1 基线的我军为 Data 未确定的出场槽位，没有 Data 0 的确定棋子，因此新增的状态目标匹配门禁提前截断了整段地图投影。

## 修复
- 0x4D、0x4E、0x53、0x5C 的单体目标在当前棋盘没有匹配时：只跳过本条视觉呈现，保留诊断，继续后续独立指令；不猜测 Data 号与我军槽位关系。
- 存在多个匹配时依然停止，防止把参数错误地应用给某个棋子。
- 参数错误以及原有移动/复活匹配规则不变，原生写回门禁不变；R 指令流不变。
- 推演中断且没有任何结果时，标题显示“推演中断，详见下方提示”，避免误报“无变化”。

## 验证

- 另验证四类未匹配辅助目标不会截断后续障碍物，歧义目标仍会停止。

## 使用
测试包只有 s.exe 与三个配套 ini。请先在原编辑器保存需要保留的未保存内容，再用本包测试；正在运行的旧进程不会自动更新为修复版。
